Goals for the project

This is a work in progress to build a website around an interactive map of Central Eurasia. The map will mark specific regions and link to the phonological inventories of the languages spoken there.

The site currently has a homepage that will host the map, and a dropdown menu linking to additional resources and pages.

Next, Google Maps will be embedded using the JavaScript API, enabling custom markers and richer interaction. Once the map is complete, the layout of the other pages will be refined and expanded, and linguistic content and resources added.

Planned translations: Kazakh, Turkish, or both, so the database is accessible to a wider audience.
